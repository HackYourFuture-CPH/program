Task

Let’s build a tiny “Should I?” board via fetch!

  1. A yes/no answer with a matching GIF fetch · querySelector · textContent · src
    • Fetch yesNoUrl
    • Set #yesno-answer text to data.answer
    • Set #yesno-image src to data.image
  2. A random joke (setup + punchline) fetch · querySelector · textContent
    • Fetch jokeUrl
    • Put data.setup into #joke-setup
    • Put data.delivery into #joke-punchline
  3. A piece of advice fetch · querySelector · textContent
    • Fetch adviceUrl
    • Set #advice-text to data.slip.advice
  4. A “Try again” button that reloads the yes/no answer querySelector · addEventListener · click · fetch
    • Get #refresh-yesno
    • On click, run the yes/no fetch again
  5. The joke updates automatically every 5 seconds setInterval
    • Call the joke fetch every jokeRefreshMs with setInterval
