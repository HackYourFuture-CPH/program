Code debugging

Open the browser inspector, read messages in the Console, and pause execution with debugger.

1. Open the inspector

DevTools lets you inspect the page, read logs, and step through JavaScript.

macOS

  • Cmd + Option + I — open DevTools
  • Cmd + Option + J — jump to Console
  • Or menu: View → Developer → Developer Tools

Windows

  • F12 — open DevTools
  • Ctrl + Shift + I — open DevTools
  • Ctrl + Shift + J — jump to Console

Linux

  • F12 — open DevTools
  • Ctrl + Shift + I — open DevTools
  • Ctrl + Shift + J — jump to Console

Right-click anywhere on the page → Inspect also works on every OS. If this demo is inside the session shell, pick the debugging iframe in the Console context dropdown.

2. console.log

Open the Console tab, then click the button. Watch what gets printed — different values look different in DevTools.

3. debugger

Open the Sources (or Debugger) panel, then click the button. Execution pauses on the debugger line — inspect variables, then resume.

DevTools must be open for debugger to pause. If nothing happens, open the inspector first, then try again.
