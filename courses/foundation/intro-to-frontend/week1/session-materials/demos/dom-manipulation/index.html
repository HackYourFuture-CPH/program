Let’s create a Friday evening playlist via JavaScript!

  1. A styled playlist title querySelector · textContent · classList · style

    • Apply titleStyles
  2. A “now playing” item at the top of the list querySelector · createElement · innerHTML · appendChild
    • Get the list (#track-list)
    • Create an li
    • Give it trackItemClassName
    • Set innerHTML to nowPlayingHtml
    • Append it to the list
  3. All tracks from our data shown in the list createElement · textContent · appendChild
    • For each name in tracks
    • Create an li
    • Add trackItemClassName
    • Set textContent
    • Append it to the list
  4. A featured podcast card with an image querySelector · createElement · appendChild
    • Get the feature slot (#feature-slot)
    • Build a card (featureCardClassName) from featured
    • Add an image only if imageUrl exists
  5. A banner above the track list createElement · insertBefore
    • Create a p, set text to bannerText, add bannerClassName
    • Insert it before the list
  6. Ready status, tab title, and viewport width in the console getElementById · textContent · classList · document · window
    • Get the status element (#status)
    • Set its text to statusReadyText
    • Add statusReadyClassName
    • Set document.title to pageTitle
